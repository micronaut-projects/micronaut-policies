Contributions are made via [pull requests](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests) and merged by the [Micronaut core development team](https://github.com/orgs/micronaut-projects/teams/core-developers).

Code changes are discussed via [GitHub Discussions](https://docs.github.com/en/discussions), [GitHub issues](https://docs.github.com/en/issues), or directly in [pull requests](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests). For big changes, contributors are encouraged to discuss them before creating a pull request.
