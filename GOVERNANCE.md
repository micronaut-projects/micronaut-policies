Micronaut is led by the Project Lead, currently [@graemerocher](https://github.com/graemerocher), and maintained by the [Micronaut Core Developer Team](https://github.com/orgs/micronaut-projects/teams/core-developers).

The Core Developer Team is responsible for:

- Reviewing and merging contributions.
- Maintaining project repositories.
- Planning releases.
- Managing technical direction.
- Coordinating security fixes.
- Protecting the project's long-term sustainability.

Work is discussed publicly through [GitHub Discussions](https://docs.github.com/en/discussions), [GitHub issues](https://docs.github.com/en/issues), and [GitHub pull requests](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests).

Decisions should be made by consensus whenever possible. When consensus cannot be reached, the matter may be escalated to the Project Lead and the Core Developer Team.
