# Assets

The Micronaut project collectively manages:

- Source code repositories.
- Release artifacts.
- Package registries.
- Build and release infrastructure.
- Documentation platforms.
- Project websites and guides.

Documentation and guides are published as static websites via [GitHub Pages](https://docs.github.com/en/pages).

Release artifacts are published to the [Maven Central Repository](https://www.sonatype.com/products/maven-central-repository) and [GitHub Releases](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases).

Gradle plugins are published to the [Gradle Plugin Portal](https://plugins.gradle.org).
