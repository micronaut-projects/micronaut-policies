# Micronaut Code of Conduct

Micronaut is a project of the [Commonhaus Foundation](https://www.commonhaus.org/). Micronaut adheres to the Commonhaus Foundation's [Code of Conduct](https://www.commonhaus.org/policies/code-of-conduct/).

If you find anyone in the Micronaut community violating the Code of Conduct, please contact [@sdelamo](https://github.com/sdelamo) or [@graemerocher](https://github.com/graemerocher).
