# Organization

## Discussion

Work is discussed publicly via [GitHub Discussions](https://docs.github.com/en/discussions), [GitHub issues](https://docs.github.com/en/issues), or [GitHub pull requests](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests).

## Planning

Work is planned with public [GitHub Projects](https://docs.github.com/en/issues/planning-and-tracking-with-projects).

There are always at least three public projects:

- A GitHub Project for the next patch release.
- A GitHub Project for the next minor release.
- A GitHub Project for the next major release.

We also have a public [GitHub Discussion Category](https://github.com/micronaut-projects/micronaut-core/discussions/categories/planning) to plan releases.
