# Release Management

Release managers are responsible for:

- Coordinating schedules.
- Managing release branches.
- Publishing release notes.
- Ensuring release quality.

Usually, the [Point of Contact](POINTS_OF_CONTACT.md) for a repository acts as the release manager for that repository, following the framework's [versioning](VERSIONS_POLICY.md).

Other members of the [Micronaut Core Developer Team](https://github.com/orgs/micronaut-projects/teams/core-developers) can trigger releases of any module.
