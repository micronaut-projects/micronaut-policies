# Succession Planning

To reduce project risk and improve sustainability:

- At least two [Maintainers](MAINTAINERS.md) should have administrative access to critical systems.
- Administrative credentials must be documented and recoverable. The project must use a password manager.
- The project should continuously develop new Maintainers.
- If all active Maintainers become unavailable, emeritus Maintainers may organize a recovery process and appoint interim Maintainers.

## Project Lead Succession

If the Project Lead steps down, a new Project Lead will be elected by the project's [Maintainers](MAINTAINERS.md).

If the [Maintainers](MAINTAINERS.md) wish to replace the Project Lead, they must approve the change proposal by at least a 2/3 vote.
