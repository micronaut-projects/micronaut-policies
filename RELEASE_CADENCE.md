# Release Cadence

Micronaut publishes an SBOM (Software Bill of Materials). It is an inventory of all the different Micronaut module versions that make up a framework release. A release of Micronaut is a release of the [`micronaut-platform` repository](https://github.com/micronaut-projects/micronaut-platform).

The release cadence goal for the framework is to release:

- Weekly patch versions
- A minor version every 4-12 weeks
- A major version bi-yearly
